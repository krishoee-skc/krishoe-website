## 🎯 First 30 Minutes

### Step 1: Get Oriented (5 min)
1. Go to `/admin/getting-started`
2. Read the quick start section
3. Understand your dashboard layout

### Step 2: Learn Shortcuts (5 min)
1. Press `?` on any page
2. Note down top 5 shortcuts:
   - `G` then `D` = Dashboard
   - `G` then `P` = Products  
   - `G` then `O` = Orders
   - `K` = Search
   - `Esc` = Close modal

### Step 3: Set Up Your Preferences (5 min)
1. Set dark/light mode (moon icon, top right)
2. Bookmark important pages
3. Bookmark Getting Started page

### Step 4: Complete First Checklist (15 min)
1. Upload first product ✓
2. Configure email notifications ✓
3. Set company info ✓

## 📸 Product Photography

**Quick Access:** `/admin/products/photo-guide`

### 6 Golden Rules:
1. ☀️ Natural daylight near window
2. ⬜ Clean white/gray background  
3. ✨ Clean shoes only
4. 📐 Shoe-level angle (not top-down)
5. 🔄 4-5 different angles per shoe
6. 🚫 No zoom - get close instead

**Upload:** Products → Edit → "Upload photo"

## ⭐ Review Moderation

**Quick Access:** `/admin/reviews`

### Your Job:
- ✓ **Approve** real, helpful reviews
- ✕ **Reject** low-quality/spam reviews
- 🚩 **Flag** suspicious/fake reviews

### Status Summary:
- 🔴 **Pending** = Needs your decision
- 🟢 **Approved** = Live on store
- 🔴 **Rejected** = Hidden from customers

## 💾 Keyboard Shortcuts Cheat Sheet

### Navigation (Use "G" method)
```
G + D = Dashboard
G + P = Products
G + O = Orders
G + R = Reviews
G + S = Settings
G + H = HR
```

### Quick Actions
```
/ = Search
? = Show all shortcuts
K = Focus search
Esc = Close anything
Ctrl/Cmd+S = Save
Ctrl/Cmd+Enter = Submit form
```
