# KRISHOE Facebook Page launch — आज राति

यो काम code बाट होइन, Facebook Page को owner access बाट हुन्छ। Website ले अहिले business Page लाई footer र Google SEO मा देखाउन तयार छ। अब Page मा यी तीन काम गर्नुहोस्।

## 1. Username दाबी गर्ने

1. KRISHOE Facebook Page मा switch गर्नुहोस्।
2. Settings & privacy → Settings → Page setup → Username खोल्नुहोस्।
3. `krishoe` उपलब्ध भए त्यही राख्नुहोस्; नभए `krishoenepal` रोज्नुहोस्।
4. Save गरेर Page link `facebook.com/krishoe` जस्तो खुलेको जाँच्नुहोस्।
